MASTROCOSTAS v1.1 — ΕΓΚΑΤΑΣΤΑΣΗ ΣΕ IPHONE / IPAD

Το site είναι ο πλήρης πηγαίος κώδικας. Δεν απαιτείται build, Node.js ή συνδρομή για χρήση. Για εγκατάσταση στο iPhone χρειάζεται μία αρχική φιλοξενία HTTPS. Δεν έχει δημοσιευτεί ακόμη από εμάς. Η εφαρμογή δεν στέλνει καταχωρίσεις πελατών σε server. Ο κώδικας είναι δημόσιος αν επιλέξετε δωρεάν δημόσιο αποθετήριο GitHub Pages. Μην ανεβάζετε αρχεία JSON/CSV, στοιχεία πελατών ή άλλα ιδιωτικά αρχεία.

Α. ΔΗΜΟΣΙΕΥΣΗ ΑΠΟ ΥΠΟΛΟΓΙΣΤΗ (GitHub Pages)
1. Αποσυμπιέστε το ZIP. Μπείτε στο https://github.com/new και συνδεθείτε ή δημιουργήστε δωρεάν λογαριασμό.
2. Δημιουργήστε δημόσιο repository με όνομα mastrocostas. Προσθέστε README για να δημιουργηθεί το main branch.
3. Add file > Upload files. Ανεβάστε τα ΠΕΡΙΕΧΟΜΕΝΑ του φακέλου site, όχι τον ίδιο τον φάκελο site ή το ZIP. Το index.html πρέπει να φαίνεται στη ρίζα και ο φάκελος icons να περιέχει όλα τα PNG. Κάντε Commit changes. Αν ο browser δεν δέχεται τον φάκελο icons, ανεβάστε τα αρχεία διατηρώντας τη διαδρομή μέσω GitHub Desktop ή git.
4. Settings > Pages > Build and deployment > Source: Deploy from a branch > Branch: main > /(root) > Save. Όταν δημοσιευτεί, πατήστε Visit site. Ελέγξτε ότι το URL αρχίζει με https://. Η διεύθυνση έχει τη μορφή https://ΟΝΟΜΑ-ΧΡΗΣΤΗ.github.io/mastrocostas/ (παράδειγμα, όχι ενεργός σύνδεσμος).
5. Κρατήστε τη διεύθυνση σταθερή. Η αλλαγή domain ή προφίλ browser μπορεί να σημαίνει ξεχωριστή αποθήκευση. Για ενημερώσεις του κώδικα αλλάξτε το VERSION στο sw.js ώστε να ανανεωθεί η offline cache.
Επίσημες οδηγίες: https://docs.github.com/en/pages/quickstart

Β. ΕΓΚΑΤΑΣΤΑΣΗ ΣΤΟ IPHONE
1. Ανοίξτε τη δημοσιευμένη διεύθυνση στο Safari με internet.
2. Περιμένετε την ένδειξη «Έτοιμη για χρήση χωρίς internet».
3. Κοινοποίηση (τετράγωνο με βέλος) > Προσθήκη στην οθόνη αφετηρίας (Add to Home Screen). Ενεργοποιήστε Open as Web App αν εμφανίζεται. Πατήστε Προσθήκη.
4. Ανοίξτε το εικονίδιο MastroCostas από την αρχική οθόνη, ακόμη με internet. Περιμένετε ξανά την ένδειξη ετοιμότητας. Η αποθήκευση της εγκατεστημένης εφαρμογής μπορεί να διαφέρει από το Safari.
5. Κάντε τον έλεγχο Γ πριν χρησιμοποιήσετε πραγματικά στοιχεία.
Επίσημες οδηγίες Apple: https://support.apple.com/en-au/guide/iphone/iph42ab2f3a7/ios

Γ. ΕΛΕΓΧΟΣ ΣΤΗ ΣΥΣΚΕΥΗ
Με internet: προσθέστε δοκιμαστική κοστολόγηση, αποθηκεύστε, κλείστε την εφαρμογή. Ενεργοποιήστε λειτουργία πτήσης και βεβαιωθείτε ότι Wi-Fi/δεδομένα είναι κλειστά. Ανοίξτε από το εικονίδιο. Ελέγξτε ιστορικό, νέα κοστολόγηση, αποθήκευση και επανεκκίνηση. Εξαγάγετε JSON στις Ρυθμίσεις και ελέγξτε στα Αρχεία/Λήψεις ότι υπάρχει. Δοκιμάστε εισαγωγή του JSON πριν από πραγματικά δεδομένα. Δοκιμάστε Δημιουργία προσφοράς και εκτύπωση/PDF μέσω του διαλόγου iOS. Αν κάποια λειτουργία αποτύχει, μην βασιστείτε σε αυτήν επαγγελματικά μέχρι να διορθωθεί.

Δ. ΜΕΤΑΦΟΡΑ ΑΠΟ v1.0 / ΑΝΤΙΓΡΑΦΑ
Στην προηγούμενη εφαρμογή: Ρυθμίσεις > Εξαγωγή JSON. Μεταφέρετε το αρχείο ιδιωτικά στο iPhone μέσω Αρχείων/iCloud Drive ή AirDrop. Στην εγκατεστημένη MastroCostas: Ρυθμίσεις > Εισαγωγή JSON. Η εισαγωγή αντικαθιστά τα δεδομένα της συσκευής, δεν συγχωνεύει. Το σχήμα δεδομένων v1 διατηρείται. Δεν υπάρχει αυτόματος συγχρονισμός. Μη διαγράφετε την εφαρμογή ή δεδομένα Safari χωρίς αντίγραφο. Ο browser μπορεί να απομακρύνει τοπική αποθήκευση/cache, π.χ. λόγω έλλειψης χώρου. Αν χαθεί η offline cache, χρειάζεται ξανά internet. Κρατήστε εβδομαδιαία αντίγραφα σε ασφαλές μέρος.

Ε. ΕΛΕΓΧΟΙ ΕΚΔΟΣΗΣ
- Node test.js: επιτυχής μαθηματικός έλεγχος.
- Node pwa_test.js: επιτυχής έλεγχος manifest και service worker με προσομοιωμένη Cache API, όχι πραγματικό offline browser.
- ui_test.py: επιτυχής δοκιμή σε Chromium σε απομονωμένο έγγραφο με προσομοιωμένη αποθήκευση: φόρμα, ιστορικό, εμφάνιση προσφοράς για εκτύπωση, διαστάσεις 320/390/768/1280 px.
- pwa_browser_test.py: δεν ολοκληρώθηκε, πολιτική Chromium ERR_BLOCKED_BY_ADMINISTRATOR στην πρόσβαση localhost. Δεν έχει γίνει πραγματική δοκιμή εγκατάστασης iPhone, μόνιμης αποθήκευσης, πραγματικού offline browser, επαναφοράς αρχείου και PDF.
Για αναπαραγωγή: αντιγράψτε τα αρχεία του φακέλου Δοκιμές στον φάκελο site, ανοίξτε τερματικό εκεί, εκτελέστε node test.js, node pwa_test.js. Για Python scripts χρειάζονται Playwright και Chromium (προσαρμόστε τη διαδρομή executable_path). Δεν απαιτούνται για χρήση. Μην ανεβάζετε τα scripts δοκιμών στον server.

MastroCostas — έκδοση 1.1 PWA

ΕΚΚΙΝΗΣΗ
1. Αποσυμπιέστε ΟΛΟ το ZIP σε έναν μόνιμο φάκελο, π.χ. Έγγραφα/MastroCostas.
2. Ανοίξτε το site/index.html με Chrome, Edge ή Firefox. Δεν απαιτείται λογαριασμός, εγκατάσταση ή internet. Μην ανοίγετε μέσα από το ZIP. Κρατήστε τα index.html, style.css, calc.js, app.js μαζί.
3. Ρυθμίσεις: ορίστε ωριαία χρέωση, αμοιβή, έξοδα και ΦΠΑ. Οι αρχικές τιμές είναι παραδείγματα (35 €/ώρα, 20 €/ώρα ελάχιστη αμοιβή, 3 €/ώρα λειτουργικά, 12% περιθώριο, ΦΠΑ ανενεργός, ενδεικτικός συντελεστής 24%). Ελέγξτε τον φορολογικό χειρισμό με λογιστή.
4. Νέα κοστολόγηση: συμπληρώστε όχημα και εργασία, προσθέστε ανταλλακτικά, ώρες και έξοδα. Επιλέξτε τιμή στη σύνοψη και αποθηκεύστε. Η τιμή που επιλέγετε περιλαμβάνει ΦΠΑ αν ενεργοποιηθεί. Όλες οι υπόλοιπες εσωτερικές τιμές είναι χωρίς ανακτήσιμο ΦΠΑ.
5. Μετά την επισκευή ανοίξτε την καταχώριση από το ιστορικό, επιλέξτε Ολοκληρωμένη, συμπληρώστε πραγματικά στοιχεία και πληρωμή. Αν αφήσετε πραγματικά πεδία κενά χρησιμοποιούνται οι εκτιμήσεις. Συμπληρώστε πραγματικές τιμές πώλησης υλικών/εργασίας εάν διαφέρουν από την προσφορά. Τα οικονομικά περιλαμβάνουν ολοκληρωμένες εργασίες ακόμη και αν δεν έχουν πληρωθεί, με ξεχωριστό ποσό εκκρεμών πληρωμών. Δεν είναι λογιστικό πρόγραμμα.
6. Προσφορά: επιλέξτε Δημιουργία προσφοράς και στον διάλογο εκτύπωσης επιλέξτε Αποθήκευση ως PDF ή εκτυπωτή. Η διαφορά μεταξύ επιμέρους χρεώσεων και τελικής τιμής εμφανίζεται ως έκπτωση ή πρόσθετη χρέωση υπηρεσίας, χωρίς εσωτερικά κόστη.
7. Κατάλογος εργασιών: οι 14 εργασίες έχουν αρχικά μηδενικές ώρες (δεν υποθέτουμε χρόνους επισκευής). Προσθέστε δικές σας ώρες και υλικά. Η προηγούμενη χρέωση εργασίας, αν είναι θετική, φορτώνεται ως σταθερή τιμή.
8. Τιμές ανταγωνισμού: εισάγετε δικές σας τιμές, σημειώνοντας αν είναι εκτίμηση. Η σύγκριση απαιτεί ίδια περιγραφή εργασίας και ίδιο όχημα (χωρίς διάκριση πεζών/κεφαλαίων). Η ποιότητα μπορεί να χρησιμοποιηθεί ως επιπλέον φίλτρο. Συγκρίνετε μόνο ισοδύναμες εργασίες και ανταλλακτικά.

ΥΠΟΛΟΓΙΣΜΟΙ
Προσαύξηση επί του κόστους γραμμής μετά την έκπτωση και με μεταφορικά γραμμής. Η κλίμακα επιλέγεται από την καθαρή τιμή ανά τεμάχιο μετά την έκπτωση. Μην εισάγετε τα ίδια μεταφορικά και στα γενικά έξοδα. Η διάγνωση χρεώνεται με την απλή ωριαία χρέωση. Η σταθερή τιμή εργασίας περιλαμβάνει διάγνωση. Η προσωπική αμοιβή αφορά όλες τις ώρες.
Απρόβλεπτα: ποσοστό επί υλικών και λοιπών εξόδων. Αν δεν δαπανηθούν, διορθώστε το πραγματικό κόστος. Αυτόματο λειτουργικό κόστος αντικαθιστά το χειροκίνητο όταν είναι ενεργό.
Ελάχιστη καθαρή τιμή: μεγαλύτερο από ελάχιστη χρέωση ή κόστος + προσωπική αμοιβή. Στόχος περιθωρίου: (κόστος + προσωπική αμοιβή)/(1-περιθώριο). Χωρίς ανταγωνισμό επιλέγεται το μέγιστο της κανονικής κοστολόγησης, του στόχου και του ελάχιστου. Με βιώσιμο στόχο ανταγωνισμού προτείνεται η υψηλότερη τιμή που τον ικανοποιεί, με προειδοποίηση αν δεν καλύπτεται το επιθυμητό περιθώριο. Αν ο στόχος δεν είναι βιώσιμος, χρησιμοποιείται η κανονική βιώσιμη τιμή. Στρογγυλοποίηση προς τα πάνω χωρίς στόχο, προς τα κάτω με βιώσιμο στόχο (εκτός αν παραβιάζεται το ελάχιστο). Οι φόροι εισοδήματος δεν υπολογίζονται.

ΑΝΤΙΓΡΑΦΑ ΑΣΦΑΛΕΙΑΣ
Ρυθμίσεις > Εξαγωγή JSON. Αποθηκεύστε σε δεύτερο μέσο κάθε εβδομάδα και πριν μετακινήσετε τον φάκελο. Ρυθμίσεις > Εισαγωγή JSON για επαναφορά (αντικαθιστά όλα τα δεδομένα). Το JSON περιλαμβάνει προσωπικά στοιχεία και δεν είναι κρυπτογραφημένο. Το CSV είναι για ανάλυση, όχι για επαναφορά. Η αφαίρεση προσωπικών δεδομένων αφαιρεί ονόματα και πινακίδες από το ιστορικό, όχι ελεύθερο κείμενο ή παλαιά αντίγραφα.
Το localStorage είναι ανά browser/προφίλ και ενδέχεται να εξαρτάται από τη διαδρομή αρχείου. Δεν συγχρονίζεται. Η συμπεριφορά file:// διαφέρει ανά browser και κινητό. Ελέγξτε αποθήκευση/επανεκκίνηση στη συσκευή σας πριν από πραγματικά δεδομένα. Μη χρησιμοποιείτε ιδιωτική περιήγηση. Εάν η συσκευή δεν ανοίγει τοπικά HTML με JavaScript, απαιτείται τοπικός web server ή άλλη συσκευή. Σε υπολογιστή με Python μπορείτε εναλλακτικά να τρέξετε python -m http.server 8765 --bind 127.0.0.1 μέσα στον φάκελο site και να ανοίξετε http://127.0.0.1:8765 (ξεχωριστή αποθήκευση από file://).
Δοκιμαστικά: Ρυθμίσεις > Προσθήκη δοκιμαστικών / Διαγραφή δοκιμαστικών. Δεν περιέχονται επινοημένες τιμές πραγματικών ανταγωνιστών.
